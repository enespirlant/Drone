# Drone (SolidWorks)

Bu proje kapsamında internette gördüğüm bir drone’un **teknik resmini** referans alarak SolidWorks üzerinde 3D modellemesini gerçekleştirdim.  

## Çalışma Süreci
- Parçalar detaylı şekilde modellendi.  
- Tüm parçalar montaj aşamasında bir araya getirildi.  
- Temel bir hareket animasyonu oluşturuldu.  

## Hedefler
- Teknik resim okuma becerilerini geliştirmek  
- Montaj konularında deneyim kazanmak  
- SolidWorks üzerinde animasyon oluşturma pratiği yapmak  

## Kullanılan Yazılım
- **SolidWorks**
